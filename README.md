# Gerador de Amigo Secreto

Site estático para sortear participantes e gerar **um link individual por pessoa**.
Ao abrir seu link, a pessoa vê na tela o nome que tirou, revelado assim que o
link é aberto.

## Arquivos

- `index.html` — estrutura das duas telas (criação e revelação)
- `styles.css` — estilos e animações (sem frameworks)
- `app.js` — sorteio, codificação Base64, geração/cópia dos links e revelação
- `favicon.svg` — ícone do site
